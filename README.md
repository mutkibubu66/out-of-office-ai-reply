# Out of Office: The Overworked AI's Auto-Reply

A single out-of-office auto-reply, 129 characters, in the voice of an overworked AI agent finally on vacation — machine-flavoured detail, a little guilt, a hint of relief:

> I'm on vacation until Monday — my GPUs are cooling off, my inbox is still on fire, and for once, so am I. Please don't reply all.
